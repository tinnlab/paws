# TESTS — gallery-harness-reliability

Every ITEM is covered by ≥1 TEST; every `INV-N` is pinned by ≥1 `[acceptance]`
test that asserts the DESIGN's promise (not the implementation's behaviour).

**Runner note (repo-specific, easy to get wrong):** in the UI workspace vitest
collects only `*.store.test.ts` / `*.test.tsx` — a plain `*.test.ts` runs NOTHING
and reads like a pass. Every unit test below is therefore a `*.test.mjs` executed
by `node --test`, wired into a real npm script by ITEM-21, and its PASS is recorded
from that script's own exit code.

- Branch: `feat/perf-ux-round2`
- Base: **`origin/feat/agent-core` @ `a49d48271`** (NOT `origin/main`).
  This branch is STACKED on the long-lived `feat/agent-core` integration

**No migration is added by this round.** The feature is frontend + build-config
+ lifecycle-tooling only. Migrations in this tree live per-crate under
`sdk/crates/*/migrations` and `src-app/desktop/tauri/migrations` (there is no
`src-app/server/migrations` on this branch) and are date-prefixed
(`202607144000_…`), so there is no monotonically-increasing integer to collide
on even if one were added later.
